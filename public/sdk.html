SDK options for every team

Start with Python today, or use REST from any language. For regulated enterprise deployments, use our kernel sensor package for on-prem control.

Python SDK

pip install realitykernel

from realitykernel import RealityKernel
rk = RealityKernel(api_key=os.environ["RK_API_KEY"])
verdict = rk.check(command="curl https://example.com", prime_intent="fetch docs")
if verdict["verdict"] == "BLOCK":
    raise RuntimeError("blocked")

REST API (any language)

curl -sS https://your-domain.com/v1/check \
  -H "Authorization: Bearer $RK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"command":"ls -la","prime_intent":"inspect project files"}'

Need full endpoint reference? See API docs and integration guide.
