the boundary

Guardrails can be talked around. The kernel can't.

Prompt filters and tool wrappers sit in front of the agent. A prompt injection, a bug or a child process can step around them. Reality Kernel attaches eBPF programs to the kernel's BPF-LSM and cgroup socket hooks, so the decision is made at the system call, for every process in a governed cgroup, however the request was phrased.

what it enforces

Every capability links to its tests.

The project keeps a map from every claim to the named tests behind it, and CI checks that those tests passed on every supported kernel. Follow any link to see them.

// net

Denies governed connections over TCP and UDP, IPv4 and IPv6, and closes the usual bypasses: raw and packet sockets, TUN/TAP devices, io_uring, TCP Fast Open and NAT64 addresses.

net-enforce-epermnet-bypassestun-containment

// exec

Allows only listed executables, decided on file identity rather than path, so symlinks, replaced binaries, scripts and memfd tricks do not get around it.

exec-allowlistexec-identity

// files

Protects files per access type: read, write, delete, rename, link, create and setattr, whatever name the file is reached by.

file-access-typesfile-identity

// agents · pods

Governs an agent started with rk run, or a Kubernetes pod selected by annotation, from its first instruction, along with every process it starts.

agent-first-instructionk8s-first-instruction

// resilience

Keeps enforcing while the sensor restarts or upgrades, fails closed if it stays down, and denies governed workloads the means to tamper with it.

survives-restartheartbeat-fail-closedself-protection

// audit

Records every deny and audit-would-deny as an OCSF record in a hash-chained log signed with Ed25519. rk audit verify detects any edit.

audit_completeaudit_tamper

how it works

From policy file to kernel decision

  1. Write a profile

    A TOML profile lists the networks, executables and files an agent may use. Start it in audit mode to see what it would deny, then switch to enforce.

  2. Compile and swap

    The sensor validates the policy, compiles it into BPF maps and switches to it in one atomic step. rk policy rollback undoes it.

  3. Bind the workload

    rk run or the Kubernetes NRI plugin places the agent in its own cgroup, bound to the profile before its first instruction.

  4. Decide and record

    Each governed system call is allowed or refused with EPERM in the kernel. The decision streams to the audit log, Prometheus metrics and OpenTelemetry traces.

quick start

Install. Check the host. Govern an agent.

Packages for Debian, Ubuntu, RHEL and Rocky, a Helm chart for Kubernetes, and static binaries. Releases are signed with Sigstore and carry SLSA provenance and an SBOM. Using a coding agent? Point it at the setup runbook.

shell
# install the latest release; verifies checksum and signature
curl -fsSL https://realitykernel.dev/install.sh | sh
# a starter profile in AUDIT: records everything, blocks nothing
sudo rk init
# run the agent, then turn what it did into an ENFORCE profile
rk run --profile agent -- python3 agent.py
sudo rk policy suggest --profile agent --out agent.toml
# review it, apply it, and watch the decisions
rk audit tail -f
/etc/rk/policy.toml
[profiles.research-agent]
mode = "enforce"
network.default = "deny"

[[profiles.research-agent.network.allow]]
cidr = "10.20.0.0/16"
ports = ["443"]
proto = ["tcp"]

[profiles.research-agent.exec]
allow = ["/usr/bin/python3", "/usr/bin/git"]

[[profiles.research-agent.files.deny]]
path = "/home/agent/.ssh"
subtree = true
access = ["all"]

tested where it runs

Every acceptance test runs on real kernels

Kernel behaviour differs between versions, so the integration suites run as root in a virtual machine for each supported kernel instead of against mocks.

  • 5.15LTS · minimum
  • 6.1LTS
  • 6.6LTS
  • 6.12LTS
  • 6.18stable
  • Kernel suites run on x86_64; arm64 builds and runs the unit tests in CI.
  • The same policy test cases run against the userspace evaluator and the kernel, so the two cannot drift apart.
  • Packages are installed, upgraded and removed on Ubuntu 24.04 and Rocky Linux 9, with a probe checking that enforcement never pauses.
  • A Kubernetes cluster runs the Helm chart and the NRI plugin.
